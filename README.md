# GlowMeUp Mobile

Mobile-first frontend prototype for GlowMeUp.

## Stack
- React Native
- Expo
- TypeScript
- Expo Router

## Current vertical slice
Welcome → Sign Up → Privacy → Know Me → Body → Face → Color → Aesthetic Profile → GlowProfile Reveal → Suits Me placeholder

## Important product rules
- GlowMeUp discovers user characteristics; it does not ask users to define their own body shape/personal color first.
- Measured, inferred, and interpretive evidence must remain distinct.
- Body-shape and seasonal-color labels are explanation layers, not the underlying representation.
- Suitability, Preference, and Trend are separate signals.
- Mock analysis in this branch is frontend-only and must not be presented as a validated AI result.

## Run locally

```bash
npm install
npx expo start
```

Then open with Expo Go / development build or launch Android/iOS simulator.
